# Детектор внимания — Flutter-клиент

Мобильное приложение (Android/iOS) по ТЗ v1.0. Горизонтальная ориентация имеет
собственную композицию: навигация вверху, сцена слева, панели справа. Вертикальная —
одноколоночная с нижней навигацией.

## Запуск

В репозитории лежат Dart-код и ресурсы, а каталоги хост-платформ не включены.
Один раз создайте их установленным Flutter SDK, затем запустите сервер и клиент:

```bash
cd flutter_app
flutter create --platforms=android,ios .  # один раз; iOS-сборка требует macOS и Xcode
flutter pub get
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000   # Android-эмулятор
flutter run -d ios --dart-define=API_BASE_URL=http://127.0.0.1:8000
```

Для эмулятора Android локальный сервер доступен как `10.0.2.2`, для iOS — `127.0.0.1`;
на реальном устройстве нужен доступный ему адрес сервера. Если используется локальный
HTTP, для Android отладки добавьте в сгенерированный `android/app/src/debug/AndroidManifest.xml`
внутри `<manifest>` строку `<application android:usesCleartextTraffic="true" />`.
Для выпуска используйте HTTPS и разрешение `android.permission.INTERNET` в основном
манифесте. Ориентация не фиксируется: поддерживаются портрет и ландшафт.

## Структура

```
lib/
  app/game_app.dart        корневой виджет, тема, GameScope
  data/models.dart         модели сервера: питомцы, магазин, уровни, состояние
  services/api.dart        HTTP-клиент (только действия, без расчётов)
  services/audio.dart      мягкие звуки и громкость
  services/device.dart     идентификатор устройства и токен
  state/game_controller.dart  состояние, тосты, все игровые действия
  theme/                   палитры тем и типографика
  widgets/                 кнопки, панели, звёзды, сердечко, валюта, фон
  screens/                 сплэш, главная, тренировки, игра, призыв, коллекция,
                           магазин, инвентарь, события, профиль, админ, тосты
  games/                   пять мини-игр + сцена открытия яйца + формулы очков
```

## Проверка

```bash
flutter analyze --no-fatal-infos
flutter test
```

CI проверяет анализ, тесты клиентских виджетов (включая ориентации, касания,
выбранные миры и уменьшение анимации), серверные тесты и сборку веб-прототипа.
Фоны поляны и святилища лежат в `assets/bg/`, прозрачные слои — в `assets/layers/`;
их компоновка — в `lib/widgets/layered_scene.dart`, движение — в
`lib/widgets/ambient_effects.dart`. Остальные темы мира сохраняют свои прежние фоны.
Каталог и метаданные общих ресурсов: [`../ATTENTION_DETECTOR_ASSETS/`](../ATTENTION_DETECTOR_ASSETS/).

Полная карта требований ТЗ — в [`../docs/TZ.md`](../docs/TZ.md).
