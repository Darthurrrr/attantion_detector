# Детектор внимания — Flutter-клиент

Мобильное приложение (Android/iOS) по ТЗ v1.0. Горизонтальная ориентация имеет
собственную композицию: навигация вверху, сцена слева, панели справа. Вертикальная —
одноколоночная с нижней навигацией.

## Запуск

```bash
cd flutter_app
flutter pub get
# сервер по умолчанию http://127.0.0.1:8000
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000   # Android-эмулятор
flutter run -d ios --dart-define=API_BASE_URL=http://127.0.0.1:8000
```

Для эмулятора Android локальный сервер доступен как `10.0.2.2`, для iOS — `127.0.0.1`.
Ориентация не фиксируется: приложение поддерживает портрет и ландшафт.

## Структура

```
lib/
  app/game_app.dart        корневой виджет, тема, GameScope
  data/models.dart         модели сервера: питомцы, магазин, уровни, состояние
  services/api.dart        HTTP-клиент (только действия, без расчётов)
  services/audio.dart      мягкие звуки и громкость
  services/device.dart     идентификатор устройства и токен
  state/game_controller.dart  состояние, тосты, все игровые действия
  theme/                   палитры тем и типографика
  widgets/                 кнопки, панели, звёзды, сердечко, валюта, фон
  screens/                 сплэш, главная, тренировки, игра, призыв, коллекция,
                           магазин, инвентарь, события, профиль, админ, тосты
  games/                   пять мини-игр + сцена открытия яйца + формулы очков
```
