# Детектор внимания — приключения Мурзика

Казуальная мобильная игра-тренажёр внимания в стиле референса: уютный фэнтези-мир,
кот-детектив Мурзик, карта уровней, коллекция питомцев и призыв из магических яиц.

Игра живёт в папке [`app/`](app) — это Vite + React + TypeScript приложение,
которое запускается прямо в браузере и работает как на телефоне, так и на компьютере
(на широком экране показывается в аккуратной «игровой» рамке).

## Что умеет приложение

- **Главная**: профиль с уровнем и опытом, монеты и кристаллы, меню разделов,
  ежедневная награда с живым таймером, глава 1 с прогрессом, кнопка «Начать».
  Мурзика можно погладить — он отвечает и пускает сердечки.
- **Карта уровней**: 15 уровней, звёзды за прохождение, закрытые уровни,
  текущий уровень с аватаром Мурзика, карточка уровня с советом и лучшим счётом.
- **Четыре мини-игры** с растущей сложностью:
  - «Найди пару» — классическая память с питомцами;
  - «Найди лишнего» — отличия по цвету, повороту, зеркальности и размеру;
  - «Поймай светлячков» — ловля только золотых искр среди обманок;
  - «Эхо кристаллов» — повтори последовательность кристаллов.
  За уровень дают 1–3 звезды, монеты, кристаллы и опыт; результат сохраняется.
- **Призыв**: яйцо с анимацией трещин, одиночные и пятёрные призывы,
  редкости от обычных до легендарных, гаранты (5-й — эпик, 10-й — легенда),
  история призывов и конвертация повторов в награды.
- **Коллекция**: 16 питомцев + загадочные слоты, фильтры по редкости, страницы,
  карточки с рамками по редкости, характеристики и «любимец», который гуляет на главной.
  У Мурзика есть три формы — плащ странника и доспех хранителя.
- **Задания, события и магазин**: ежедневные задания с прогрессом и наградами,
  марафон внимания, сундуки, обмен монет на кристаллы, ежедневная серия наград.
- **Настройки**: имя игрока, звук и громкость, статистика, сброс прогресса.
- Прогресс автоматически сохраняется в `localStorage`, звуки синтезируются и
  проигрываются из локальных WAV-файлов, есть вибро-отклик на телефоне.

## Запуск

```bash
cd app
npm install
npm run dev -- --host 0.0.0.0 --port 5173
```

Откройте `http://localhost:5173`. Для production-сборки:

```bash
cd app
npm run build
npm run preview
```

## Технологии и структура

- **React 19 + TypeScript + Vite 6**, без тяжёлых UI-библиотек: весь интерфейс
  собран на CSS (градиенты, объёмные кнопки, рамки, анимации, адаптивная вёрстка).
- Шрифт Nunito (кириллица) подключается локально через `@fontsource-variable/nunito`.
- Состояние игры — React-контекст в `app/src/game/store.tsx`, данные питомцев,
  уровней и наград — в `app/src/game/data.ts`.
- Экраны — `app/src/screens`, мини-игры — `app/src/games`,
  общие компоненты — `app/src/components`, стили — `app/src/styles`.

```
app/
├── public/assets/       # фоны, питомцы, яйца, иконки, звуки
├── src/
│   ├── components/      # кнопки, ленты, модальные окна, тосты, иконки
│   ├── game/            # состояние, данные, звук
│   ├── games/           # четыре мини-игры
│   ├── screens/         # главная, карта, призыв, коллекция, игра, модалки
│   └── styles/          # оформление
└── index.html
```

## Ассеты

Иллюстрации питомцев, фоны и звуки взяты из архива
`attention_detector_landscape_redesign.zip` (Flutter-версия игры) и приведены к
web-формату (WebP/PNG), а фоны храма призыва и галереи коллекции дорисованы под
новый интерфейс. Кот Мурзик в трёх формах вырезан из присланного арта.

Звуковые эффекты: `ui_tap`, `success_chime`, `crystal_reward`, `pet_cuddle`,
`soft_transition`. Музыка не используется — игра не навязывает звук и уважает
настройку «Звуки».

## Управление

Всё управляется касанием или мышью. Кнопка «Назад» есть на каждом внутреннем экране,
Esc закрывает модальные окна, настройки звука доступны с главной и из профиля.
